## Getting Started

1. Using VSCode with some extensions for project's style!
2. Install prettier and eslint extension (CRT + SHIFT + X) and find it.
3. Set prettier as default formating (can refer .vscode/settings.json) in project.
   "editor.defaultFormatter": "esbenp.prettier-vscode"

## State Management

1. This project using design patern
2. More infor in /drawing/READ-FLOW.md

## Fix coding style

1. Update .eslintrc.json if you have some good new rules.
2. Run script "npm run format" or "yarn format" ... (details in package.json).

## Run project

1. npm install
2. npm run dev
